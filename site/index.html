このサイトについて

YouTube チャンネル「思わず話したくなる雑学」の公式ページです。動物・宇宙・人体・食べ物・身近なモノなどの雑学を、出典を確認したうえで短い動画にしてお届けしています。

shorts-factory（動画投稿ツール）

当チャンネルでは、自作の投稿ツール「shorts-factory」を使い、チャンネル運営者自身が制作した動画を、運営者自身の YouTube チャンネルへアップロードしています。このツールは YouTube API サービスを利用しています。運営者以外のユーザーのデータを取得・保存することはありません。
