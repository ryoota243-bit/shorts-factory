プライバシーポリシー

shorts-factory / 思わず話したくなる雑学

最終更新日：2026年11月25日

1. 対象

本ポリシーは、YouTube チャンネル「思わず話したくなる雑学」の運営者（以下「運営者」）が使用する投稿ツール「shorts-factory」（以下「本ツール」）に適用されます。

2. YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いについては、Google プライバシーポリシーをご確認ください。

3. 取得する情報と利用目的

本ツールは、運営者本人の Google アカウントで許可された範囲（動画のアップロードと、アップロードした動画のサムネイル設定）でのみ YouTube API を利用します。運営者以外のユーザーの個人情報や YouTube のデータを取得・保存・共有することはありません。

認証に必要なトークンは、運営者が管理する非公開の環境に暗号化して保管し、動画のアップロード以外の目的には使用しません。

4. 第三者への提供

本ツールが扱う情報を、法令に基づく場合を除き第三者に提供することはありません。

5. アクセス権の取り消し

本ツールに付与したアクセス権は、Google アカウントのセキュリティ設定ページからいつでも取り消すことができます。

6. Cookie 等

本サイトおよび本ツールは、Cookie やトラッキング技術を使用していません。

7. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネル「思わず話したくなる雑学」の概要ページに記載の連絡先までお願いします。

8. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点から有効となります。
